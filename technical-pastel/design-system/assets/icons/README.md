# Icons

Line icons on a 24 grid, 1.5px stroke, square caps and miter joins, single ink `#12161c` (`ink`, light theme). In code, use the `Icon` component instead, which draws in `currentColor`. Show them at 16, 20 or 24px.

Tools: `select`, `move`, `pen`, `shape`, `text`, `frame`, `crop`, `measure`. Structure: `layers`, `grid`, `eye`, `lock`, `sliders`. Transport: `play`, `pause`, `record`. Actions: `add`, `close`, `more`, `search`, `export`, `undo`, `redo`, `chevron`. Status: `check`, `warning`.
